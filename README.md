15| ## Project Overview
16| 
17| Search123 is a web search instance powered by SearXNG, a well-known open-source metasearch engine. SearXNG focuses on privacy, aggregation, and decentralization in the search process, and Search123 builds on that foundation to provide an accessible public search experience.
18| 
19| The project is more than a simple search frontend. It represents an approach to public search that values:
20| 
21| - privacy-conscious operation
22| - easy public access
23| - maintainability
24| - a cleaner interface
25| - transparency in project documentation
26| - a flexible architecture for future growth
27| 
28| ## Why Search123 Exists
29| 
30| The internet is dominated by a small number of highly centralized search services. While these services are highly functional, they are often associated with aggressive data collection, user profiling, and reduced transparency.
31| 
32| This project is intended to deliver an experience that is:
33| 
34| - easy to use
35| - understandable to maintainers
36| - public and accessible
37| - aligned with privacy-first principles
38| - supported by open-source search infrastructure
39| - suitable for future customization and extension
40| 
41| ## Relationship to SearXNG
42| 
43| Search123 is built on top of SearXNG and uses it as the underlying metasearch engine. This gives Search123 access to the same core principles that make SearXNG valuable: aggregation of multiple upstream sources, reduced dependence on a single provider, privacy-oriented operation, and a community-driven open-source foundation.
44| 
45| The domains in which Search123 aligns with SearXNG include:
46| 
47| - metasearch-style result aggregation
48| - reduced dependence on a single search provider
49| - privacy-oriented operational philosophy
50| - user-friendly result presentation
51| - self-hosting and customization potential
52| - community-driven, open-source influence
53| 
54| This project is therefore best described as Powered by SearXNG rather than as a proprietary or closed search ecosystem.

361| ## Set Search123 as your default search engine
362| 
363| You can make Search123 your default search engine in most browsers by adding it manually.
364| 
365| ### Chrome / Edge / Brave / Chromium
366| 
367| 1. Open your browser settings.
368| 2. Go to:
369|    - Chrome: `chrome://settings/searchEngines`
370|    - Edge: `edge://settings/searchEngines`
371|    - Brave: `brave://settings/searchEngines`
372| 3. Under “Search engines,” click “Manage search engines and site search”.
373| 4. Click “Add”.
374| 5. Fill in:
375|    - Search engine: `Search123`
376|    - Keyword: `search123`
| 376|    - URL with %s in place of query:
377|      `https://search123.dpdns.org/search?q=%s`
378| 6. Click “Add”.
379| 7. Click the three-dot menu next to “Search123” and choose “Make default”.
380| 
381| ### Firefox
382| 
383| 1. Open Firefox settings.
384| 2. Go to the “Search” section.
385| 3. Under “Default Search Engine,” choose “Search123”.
386| 4. If Search123 is not listed:
387|    - Visit https://search123.dpdns.org/
388|    - Click the search box
389|    - Add it as a search engine from the browser prompt, or select it from the available search options
390| 
391| ### Safari
392| 
393| 1. Open Safari.
394| 2. Go to Safari > Settings > Search.
395| 3. Select your preferred search engine if available.
394| 4. If custom engines are not supported, use Chrome, Edge, or Firefox for the best experience.
