Search123 stands on the shoulders of several key contributors and projects.

## Cheesy Studios

Cheesy Studios is the creator and maintainer of the Search123 project. Their work includes project setup, documentation, branding, and deployment planning.

Learn more: https://www.cheesy-studios.22web.org/homepagina

## SearXNG

Search123 is built as an adaptation of SearXNG, an open-source metasearch engine project.

- SearXNG repository: https://github.com/searxng/searxng
- SearXNG license: https://github.com/searxng/searxng/blob/master/LICENSE

Search123 uses SearXNG as the underlying technology and preserves the upstream project attribution in its documentation, branding, and deployment guidance.

## Search123 open-source integration

The repository includes a reviewed SearXNG setup under `searxng/` and a safe example deployment configuration for local testing and self-hosting. These files were reviewed for obvious secrets, placeholder values, and duplicate production content before being integrated.

The exported public-source files were treated as a sanitized example reference and were not copied blindly into a production deployment.
