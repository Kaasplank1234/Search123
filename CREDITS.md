## SearXNG

Search123 is built as an inspired adaptation of **SearXNG**, an exceptional open-source metasearch engine project.

**SearXNG Repository:** [https://github.com/searxng/searxng](https://github.com/searxng/searxng)

**SearXNG License:** [GNU Affero General Public License v3.0 (AGPL-3.0)](https://github.com/searxng/searxng/blob/master/LICENSE)

SearXNG provides the underlying philosophy, architecture, and technical foundation that inspired Search123's approach to privacy-conscious, decentralized search. Search123 adapts and extends these principles for a streamlined public search experience.
